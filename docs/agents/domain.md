# Domain Docs

Single-context layout: one `CONTEXT.md` at the repo root, plus Architecture Decision Records under `docs/adr/`.

## Consumer rules

When working on this project, read:

1. `CONTEXT.md` — project-level architecture and conventions
2. `docs/adr/` — architecture decision records (if the task involves design decisions that may have prior ADRs)

Create an ADR at `docs/adr/` for any non-trivial architecture decision made during the task.
