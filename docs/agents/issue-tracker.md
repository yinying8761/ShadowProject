# Issue Tracker

Issues are tracked in **GitHub Issues** at `https://github.com/yinying8761/ShadowProject/issues`.

Use the `gh` CLI to interact with issues:

```bash
gh issue list
gh issue create --title "..." --body "..."
gh issue view <number>
gh issue close <number>
```

PRs as a request surface: **disabled**. Only project maintainers create pull requests.
