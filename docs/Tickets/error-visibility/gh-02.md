# 02 — 前端：重试瞬态提示 + 内联错误气泡

**What to build:** 断网发消息后，聊天区出现「网络连接失败，正在重试 (n/5)」瞬态提示，重试结束
（成功或彻底失败）立即消失；彻底失败时聊天流内出现内联红色错误气泡——人话主文案 + 可展开的
原始错误信息，手动关闭、刷新即清、切会话即清。数据库不写任何错误记录。前端无测试框架 → 手动冒烟。

**Blocked by:** #01（issue #38，需要 `llm_retry` 事件联通）

**Issue:** #39

**Status:** ready-for-agent

**关键语义：**

- 错误文案映射（集中一处，默认中文，不做英文版）：
  - 连接类（connection / network）→ 「网络连接失败，请检查网络或稍后重试」
  - 超时（timeout / timed out）→ 「响应超时，请稍后重试」
  - 其余 → 「出错了，请稍后重试」
  - 原始 message 放可展开详情。
- `retryState` 瞬态：任何后续事件（token / done / error）到达即清除。
- `errorBubble` 持久：手动关闭；切会话清除。两者都只存 chatStore 内存，不落库。
