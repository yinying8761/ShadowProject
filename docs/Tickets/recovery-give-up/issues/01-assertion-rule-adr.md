# 01 — 断言规则：ADR-0012 补充条款（先立规则）

**What to build:** 把「断言只约束可判定的性质，不约束用词」写成 ADR-0012 的补充条款：允许断言的只有四类——是否带来源、是否说明未完成、是否停手、调用次数上界；关键词只许用于硬事实（URL/数字/协议标记），语义判断交给评分模型或人。这是后续改断言用例的前置依据，避免退化成「逐例补关键词」。
