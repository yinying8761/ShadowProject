# 03 — 轮次耗尽的收尾：不许空回答

**What to build:** 工具轮次（5 轮）用尽时，必须产出一句收尾——说明工具一直失败/没拿到内容；若收尾请求仍返回空（模型或网络问题），由代码写一句固定文案，绝不返回空。

**Blocked by:** None — 可立即开始。

**Status:** ready-for-agent

**参考:** docs/specs/recovery-give-up.md

- [ ] 轮次耗尽后必有非空回答（R01 的那种空回答不再出现）
- [ ] 收尾请求不带工具，且不计入工具失败账本
- [ ] 模型返回空时使用固定文案兜底（单测覆盖）
- [ ] 收尾不改变 max_tool_rounds=5 的既有上限
