# 02 — 失败账本：同一工具连续失败 2 次即禁用

**What to build:** 主循环按工具记连续失败账本：同一工具连续失败 2 次后本轮禁止再调，允许换 1 个替代工具，替代也失败就停止并如实报告。账本放硬限制（loop），不靠 prompt；用户拒绝审批不计入账本，但该工具本轮停用。

**Blocked by:** None — 可立即开始。

**Status:** ready-for-agent

**参考:** docs/specs/recovery-give-up.md

- [ ] 同一工具连续失败 2 次后，本轮不再调用它（日志可见账本状态）
- [ ] 任意一次成功把该工具的计数清零
- [ ] 禁用后允许换 1 个不同工具；替代失败立即停止，不再尝试其它工具
- [ ] 未通过审批的调用不计入失败账本，但该工具本轮停用
- [ ] 纯逻辑可单测：注入假 runtime 验证计数/清零/禁用/替代/停止五条路径
- [ ] 全量测试不低于当前基线（866 passed，排除 2 个 MCP 模块）
