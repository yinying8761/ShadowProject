# 02 — 视觉：截图进入当轮对话（主模型直接看图）

**What to build:** 用户说「看看我屏幕」时，截图作为图片内容块附在当轮用户消息上，由主模型直接描述——不再经由另一个视觉模型转述，也不再把一段屏幕文字拼进用户消息。截图只存在于这一次请求，不落库。

**Blocked by:** 01（本目录内的编号）

**Status:** ready-for-agent

**参考:** docs/specs/multimodal-vision.md

- [ ] 支持视觉的模型：说「看看我屏幕」后角色能描述屏幕内容，日志显示走的是主模型视觉
- [ ] 图片块形状按 image_api 分派（OpenAI 兼容 / Anthropic），未知形状显式报错而不是静默发纯文本
- [ ] 图片不写入消息表、摘要或记忆；历史里只有用户原话与角色回复
- [ ] 同一屏连说两次「看看」，两次都真的去看（用户发起的看屏幕永不去重）；主动陪伴的指纹去重与节流行为不变
- [ ] 回归：纯文本对话的请求体与响应不变
