# 06 — 群记忆与 compact（打开时补账）

**What to build:** 打开群对话时后台补账：先把该窗口内的内容**提取成记忆**（一次提取、每个成员各存一份），
**再 compact**（摘要 + 裁剪）。隔数日再打开时一次性补齐；记忆时间用**消息真实日期**，不把三天前说成今天。

**Blocked by:** #04（"打开即补账"的钩子挂在群聊路径上）

**Status:** ready-for-agent

**参考:** `docs/specs/group-chat.md`（Phase 2 · 群记忆与 compact）

**关键语义：**

- **触发**：打开群对话时启动**后台任务**（不阻塞聊天），同一对话 **in-flight 去重**。
- **顺序固定：先提取 → 后 compact**——交换顺序会先删掉消息、导致提取丢内容。
- **提取一次 → 存储 N 份**：一次 LLM 提取，同一批事实对**每个成员各存一份**（`character_id` = 成员）。
  *不要* 对每个成员各跑一次提取（会产生成员间记忆不一致）。
- **提示词硬性限定**：「只提取关于用户的持久事实，不提取任何角色的观点或群内对话过程」
  （否则 A 在群里的观点会污染 B 的记忆）。
- **补账**：锚点 = `Conversation.last_extract_at`；跨多日再打开时一次性处理该窗口内容并更新锚点；
  记忆 `created_at` 用**消息真实日期**。
- **compact**：复用现有摘要 + 裁剪；群对话的摘要输入同样走时间戳渲染（保留"谁说了什么"）。

## Checklist

- [ ] 拆分现有记忆提取器的「提取」与「存储」（提取一次 → 对每个成员存一次）
- [ ] 群提取提示词限定（只提取用户持久事实，不提取角色观点）
- [ ] 打开群对话触发后台任务：先提取 → 后 compact；同对话 in-flight 去重
- [ ] 跨日补账：按 `last_extract_at` 处理窗口并更新锚点
- [ ] 记忆 `created_at` 用消息真实日期
- [ ] 测试（注入假 LLM + 内存 store）：提取一次、N 份存储、提示词限定、提取→compact 顺序、补账窗口与锚点更新
- [ ] 手工验收：群聊几天后再打开 → 记忆生成且日期正确；角色能回忆起那几天的事
- [ ] 全量回归：`python -m pytest tests/ -v`
