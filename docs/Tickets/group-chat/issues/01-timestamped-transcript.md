# 01 — 时间戳对话记录（Phase 1）

**What to build:** AI 看到的对话记录带上「时间 + 说话人」——`2026/9/20 14:25 [说话人]: 内容`；
用户打开历史记录也能看到同样的格式；聊天气泡不变。1:1 立即受益（角色有时间感），同时为群聊铺好
发言者字段与渲染。

**Blocked by:** None — 可直接开始。

**Status:** ready-for-agent

**参考:** `docs/specs/group-chat.md`（Phase 1）

**关键语义：**

- **一个渲染器、两个消费者**：新建纯函数渲染器；① 喂 LLM 的上下文组装 ② 历史记录接口与前端历史视图，
  两者调用同一处，**禁止各写一份**。
- 时间：`Message.created_at` 按**系统本地时区**；格式显式拼接 `年/月/日 时:分`（月/日不补零；
  **Windows 的 strftime 不支持 `%-m`/`%-d`**，不能直接用）。
- 说话人：用户消息 → 用户画像的 `user_name`（缺省「用户」）；1:1 的 AI 消息 → 该会话的角色名。
- **仅 user/assistant 文本消息**加前缀；`tool` 角色消息与工具调用载体**不加**。
- `Message.speaker_id`（可空）走增量迁移；1:1 留空（说话人由会话角色派生）。
- 聊天气泡不变；流式过程中不显示时间戳。

## Checklist

- [ ] 新建对话记录渲染器（纯函数）：消息列表 → `YYYY/M/D HH:MM [说话人]: 内容`
- [ ] 接入喂 LLM 的上下文组装（1:1 生效）
- [ ] 历史记录接口返回时间戳与说话人；前端历史视图展示该格式
- [ ] `Message.speaker_id` 可空列（增量迁移）
- [ ] 测试：渲染器纯函数（跨天、月日不补零、tool 消息不加前缀、无名用户缺省）+ 历史接口（TestClient）
- [ ] 手工验收：1:1 聊完翻历史看到 `时间 [说话人]: 内容`；聊天气泡无变化
- [ ] 全量回归：`python -m pytest tests/ -v`
