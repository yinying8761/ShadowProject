# 03 — 群实体 API（建群 / 编辑群 / 群列表 / 群对话）

**What to build:** 群的管理后端：创建群（名称 + 成员及顺序）、改名、增删成员、群列表、为群创建对话。
做完后能通过 REST 完整管理「群」这一实体（此时还没有群聊界面）。

**Blocked by:** #02（需要群与群对话的数据模型）

**Status:** ready-for-agent

**参考:** `docs/specs/group-chat.md`（Phase 2 · 群实体与数据模型）

**关键语义：**

- 群 = **固定成员集合**；成员顺序即发言顺序。「编辑群」是**管理操作**（不是聊天中实时进出）。
- 一个群可以开**多条对话**（对应前端"新对话"），对话归属 `group_id`。
- 错误语义与现有 REST 一致（对象不存在 → 404；非法输入 → 明确错误）。
- 群成员至少 1 个（否则无法发言）。

## Checklist

- [ ] 建群 API（名称 + 成员列表与顺序）
- [ ] 编辑群 API：改名、增删成员、调整顺序
- [ ] 群列表 API（含成员与对话概要）
- [ ] 为群创建对话 API（支持一个群多条对话）
- [ ] 测试（TestClient + 内存 SQLite）：建群往返、编辑群、群列表、群对话归属 `group_id`、不存在 → 404
- [ ] 全量回归：`python -m pytest tests/ -v`
