# 05 — 群聊前端界面

**What to build:** 用户可见的群聊：设置面板左栏新增「群聊」→ 右侧群列表 + 创建群（起名 + 选成员）+
编辑群；点击群名**进入群聊**（强制完整模式）；群窗口左上角成员列表、左侧对话记录标题、左下角「新对话」；
消息按说话人区分。做完后用户能真正建群、进群、和多个角色聊天。

**Blocked by:** #04（群聊后端能力）

**Status:** ready-for-agent

**参考:** `docs/specs/group-chat.md`（Phase 2 · 前端）

**关键语义：**

- 设置面板新增「群聊」项（现有导航是 NavKey + 项数组的模式，照此扩展）。
- 点群名进入群聊：关闭设置面板 → 切换**完整模式** → 载入该群对话；**退出群聊回单聊时恢复进入前的模式**。
- 群聊**强制完整模式**（紧凑模式没有群聊界面）。
- 群内消息按说话人区分（名字 + 视觉标识）；历史记录沿用时间戳格式（#01）。
- **群聊不触发 TTS**（预留开关，见 spec Out of Scope）。
- 复用现有聊天 WebSocket（单连接），不新开通道。

## Checklist

- [ ] 设置面板新增「群聊」项：群列表 + 创建群 + 编辑群（改名/增删成员）
- [ ] 点击群名进入群聊（关闭设置、切完整模式、载入该群对话）
- [ ] 群窗口：左上成员列表、左侧对话记录标题、左下「新对话」
- [ ] 消息按说话人区分（名字 + 视觉标识）
- [ ] 群聊不触发 TTS（保留开关位）
- [ ] 手工验收：建群 → 进群 → 发一句 → 角色依次回应；无话可说的角色保持沉默；模式切换行为正确
- [ ] 1:1 界面与聊天 WebSocket 不受影响
