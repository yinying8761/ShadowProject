# 07 — 群消息单调序号 + 排序切换（前置）

**What to build:** 每条消息在它所属会话内获得**单调递增序号**；所有读路径（喂 LLM 的上下文、历史
记录接口、群摘要与群记忆补账读取）一律按该序号排序 → 并发写入下「谁先说的」永远确定：同一秒写入
多条不再并列、反复重读顺序稳定。既有数据回填，**1:1 可见行为保持不变**。

**Blocked by:** None — 可直接开始。

**Status:** ready-for-agent

**参考:** `docs/specs/group-chat.md`（群轮编排 · 落库顺序）、`docs/adr/0009-concurrent-group-turns.md`

**关键语义：**

- 序号在**写入时按会话分配**（每会话单调递增），**不是**从时间戳派生。
- 既有行必须**回填**（按 `created_at` 升序、每会话独立编号）——留 NULL 就会让排序继续抖动，等于没做。
- 排序切换要覆盖**所有读路径**：LLM 上下文组装、历史记录接口、群摘要与群记忆补账；**漏掉任何一处就会出现"两处顺序不一致"**。
- **1:1 的可见行为必须不变**（纯增量）：1:1 既有的顺序语义不能被这次改动改写。
- 走**增量迁移（加列）+ 回填**，不要重建表。

## Checklist

- [ ] 消息模型增加可空整数序号（增量迁移）
- [ ] 既有数据回填（按 `created_at` 升序、每会话独立编号）
- [ ] 写入路径分配序号（每会话单调）
- [ ] 所有读路径改按序号排序（LLM 上下文 / 历史接口 / 群摘要与补账）
- [ ] 测试：同一秒并发插入多条 → 顺序稳定且等于写入顺序；反复重读一致；回填正确；1:1 行为不变
- [ ] 全量回归：`python -m pytest tests/ -v`
