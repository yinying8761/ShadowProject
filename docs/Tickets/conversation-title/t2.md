## Parent

#34（对话命名 — AI 自动命名 + 手动改名，Workflow H）

## What to build

前端端到端：聊完一轮后，侧边栏**立即**出现 AI 起的标题（无需切换会话）；会话条目 hover 出现编辑键（删除键左侧），点击进入行内编辑——Enter 确认（调改名端点并即时更新本地列表）、Esc / 右键取消恢复原标题；title 为默认值的会话显示本地化「新对话」而不是英文原始值。

## Acceptance criteria

- [ ] AI 起好标题后，侧边栏自动刷新显示新标题：chatStore 在 `done` 后置「会话列表已脏」版本计数，侧边栏订阅计数变化重拉列表
- [ ] title 为默认值的会话显示 `t('New Conversation')`（词条已有，改走 i18n 而非直接渲染原始值）
- [ ] 编辑键位于删除键左侧，hover 显现（与删除键交互一致）；点击进入行内编辑（输入框替换标题，不弹对话框）
- [ ] Enter 确认 → 调改名端点，成功后本地列表即时更新；Esc / 右键取消 → 恢复原标题、退出编辑态
- [ ] 空/全空白输入不可提交（禁用确认或不生效）
- [ ] api 服务层新增改名方法；i18n 词条新增或复用（编辑/取消等）
- [ ] 手工冒烟：新会话聊一句 → 标题自动出现 → 改名 → AI 不再覆盖；Esc/右键取消不落库
